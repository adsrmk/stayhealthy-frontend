# StayHealthy

StayHealthy is a fictitious non-profit healthcare front-end project focused on helping patients in remote and underserved areas connect with trusted doctors and access essential medical services online.

## Project overview

The application provides a responsive, patient-friendly interface for finding doctors, creating accounts, logging in, booking appointments, managing profile information, and accessing healthcare-related services.

## Tech stack

- React.js
- HTML5
- CSS3
- JavaScript
- Responsive web design

## Setup instructions

### 1. Clone the repository

```bash
git clone https://github.com/adsrmk/stayhealthy-frontend.git
cd stayhealthy-frontend
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start the development server

```bash
npm start
```

The application will normally be available at `http://localhost:3000`.

### 4. Create a production build

```bash
npm run build
```

The optimized production files will be generated in the `build` directory.

## Main features

- Responsive StayHealthy navigation
- Patient sign-up and login
- Doctor search
- Appointment booking
- Profile management
- Reviews and feedback
- Accessible, patient-friendly UI
